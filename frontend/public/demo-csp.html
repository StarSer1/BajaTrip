Demostración: la CSP bloquea un script

Esta página trae un <script> escrito dentro del HTML, como lo dejaría alguien que logró inyectar código. Si se ejecutara, cambiaría el texto de abajo a rojo y diría «El script se ejecutó».

El script NO se ejecutó: la política de seguridad de contenido lo bloqueó.

Abre F12 › Consola: verás el aviso Refused to execute inline script because it violates the following Content Security Policy directive: "script-src 'self' …". El bloqueo también queda en la bitácora del servidor (docker compose logs app1 app2 | findstr csp-bloqueo).
